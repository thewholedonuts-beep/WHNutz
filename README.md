# WHNutz legacy public experience

The maintained public +U experience is **[wenevergonnaclose.com](https://wenevergonnaclose.com/)**, deployed from [`thewholedonuts-beep/wholedonuts-universe`](https://github.com/thewholedonuts-beep/wholedonuts-universe). This repository preserves an earlier, independently reachable static experience at **[thewholedonuts-beep.github.io/WHNutz/](https://thewholedonuts-beep.github.io/WHNutz/)**.

## Public boundaries

- This repository does not own `wenevergonnaclose.com`, its DNS, or its CNAME. The canonical repository owns the verified custom-domain deployment.
- The legacy page's templates, guide, and interactive world remain usable locally. Its visible link to the maintained site is a clearly labeled forward handoff, not a domain claim.
- The optional +U link is generated and stored only in the visitor's browser. This site does not send it to a QR, analytics, or other third-party provider.
- The Crumb Workshop and Dedication Award integrations are intentionally unconfigured here. They do not accept or transmit submissions until the canonical site publishes a reviewed, consent-based path.

## Storefront and support

`storefront-config.js` is public, contains no credentials, and remains empty until a separate Shopify + Printful storefront is independently verified. Empty, malformed, non-HTTPS, and credential-bearing URLs keep the Goods Window browse-only. The Cash App link is an optional external support handoff; it does not purchase merchandise and has its own provider terms and privacy practices.

## Provenance reconciliation

The canonical public launch already carries the public templates, guide, static experience, world, and storefront configuration in its own maintained form. The following legacy materials are deliberately not imported automatically: `auth.js`, `auth-config.js`, the Supabase migrations, and former launch instructions. They require a separate owner review for data handling, access controls, and deployment compatibility before any use in the canonical site. `world/README.md` is retained as historical source context only.

No claim is made that this legacy repository is indexed, discoverable, or the authoritative public entry.
